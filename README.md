## ✨ 功能特性

### 前台网站
- **首页** - 品牌展示、热销推荐、品类导航
- **产品页** - 分类筛选、排序、搜索
- **关于页** - 公司简介、品牌故事、联系方式
- 响应式设计（手机/平板/电脑）
- 购物车功能
- 邮件订阅

### 后台管理
- 安全登录验证
- 产品数据概览
- 添加/编辑/删除产品
- 多品类管理
- 实时同步到前台

## 🛠️ 技术栈

- **框架**: Next.js 16
- **语言**: TypeScript
- **样式**: Tailwind CSS
- **数据存储**: LocalStorage（演示版）

## 📦 本地开发

```bash
cd cosmetics-shop
npm run dev
```

访问 http://localhost:3000
